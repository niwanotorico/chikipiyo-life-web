## 描画確認で見つけて直したこと
1. 翼の「先」を一番遠い頂点にしたら翼の後ろ端が選ばれ、翼が上向きに反った → 垂らした時の一番下の頂点に変更
2. 通常カメラでは画面が頭と前の枠で隠れる → PC上にホログラムを追加（「小さな未来のおうち」の世界観に合わせる）
3. ホログラムの白い点と線が窓の明るさに負ける → オレンジ系の線と大きめの点、面はクリーム色に
4. 到着位置と spot の最大5cmのずれでホップの始まりと終わりが跳ぶ → root の実位置を基準に
5. ジャンプ中の翼が片方だけ真上に立つ → 回転方向の符号を直し、振り幅を小さく
6. ヘッドホンが歩き出した瞬間に消える → 降りる直前に外して机へ戻す
7. 背中側から打鍵が見えない → キーを打つたびに肩を小さく左右に揺らす
8. 打鍵中の翼は大きな頭の下に隠れる（真上・背後からは見えない）→ 物理的には届いている。低い横アングルでは見える
