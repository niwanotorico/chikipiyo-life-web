# Blender編集用の家具

現在のWeb家具をそのまま書き出したGLBです。各家具の部品・色を保持しています。

| ファイル | 内容 |
| --- | --- |
| bed.glb | ベッド |
| sofa.glb | ソファ |
| table.glb | 食卓（皿・食べ物を含む） |
| kitchen.glb | キッチン（鍋・水栓を含む） |
| fridge.glb | 冷蔵庫 |
| vr.glb | VR用テーブルと置かれたヘッドセット |
| desk.glb | 作業机と隣接する造形プレート・黄色い家 |
| furniture-layout.glb | 全家具を現在の部屋内配置に並べたもの |

Blenderの「ファイル → インポート → glTF 2.0」で開けます。
個別ファイルは家具の設置原点を (0,0,0) にしています。一式ファイルは部屋内の配置を保持しています。
glTFはYが上・Zが前で、BlenderではインポーターがZ上へ変換します。スケールは1のまま編集してください。
各部品は独立したメッシュで、`sofa_part_01` のように名前が付いています。

座る場所・寝る場所などとの整合を保つため、原点や全体スケールは動かさず、座面や天板の高さもできるだけ維持してください。
現在の配置・行動位置・向きは `layout.json` に記録しています。

**編集したGLBはまだWebへ自動反映されません。** 現在のWebは家具をコードで生成しています。
編集後にGLBを読み込む対応を追加する必要があります。元のWebコードや公開版は今回変更していません。

再書き出し: `node scripts/export-furniture.mjs`（同名GLBを上書きするため、Blenderで編集したファイルは別名で保存してください）。
