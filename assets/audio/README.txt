川のせせらぎ音源の置き場所

river-stream.ogg / river-stream.m4a / river-stream.mp3 / river-stream.wav のどれかを置くと、渓流ページ（river.html）で自動的に鳴ります。
複数置いた場合は ogg → m4a → mp3 → wav の順で、ブラウザが再生できるものを使います。
推奨：モノラル / 48kHz(または44.1kHz) / 30〜60秒 / 一定の音量で、鳥の声など目立つ出来事が入っていないもの。
ループの継ぎ目はプログラム側で1.2秒クロスフェードして消すので、素材の頭と終わりにフェードは付けないでください。
